If you’ve browsed SSD listings, you’ve seen terms thrown around as if they mean the same thing. They don’t.

NGFF and M.2 are the same thing. NGFF stood for Next Generation Form Factor, the working name before the standard was finalized. Sellers still use “NGFF,” mostly for SATA M.2 drives.

M.2 is a shape. It describes how the card looks and plugs in. It says nothing about speed.

SATA and NVMe are the speed lanes. SATA is capped at roughly 550 MB/s. NVMe runs over PCIe and can reach thousands of MB/s. So an M.2 SATA drive is no faster than a 2.5-inch SATA SSD, only smaller.

Three physical checks decide whether a drive fits:

1. The key. The notch in the gold connector blocks incompatible sockets. B-key sockets support SATA and PCIe x2, M-key sockets support SATA and PCIe x4, and B+M drives (usually SATA) fit either. But fit isn’t the same as working. A B+M SATA drive may slot into an M-key socket that only supports PCIe.

2. The length. The first two digits of a code like 2280 are the width in millimetres (always 22) and the rest is the length. 2280 is the most common, but compact laptops often use 2230 or 2242.

3. The generation. A PCIe 4.0 drive in a PCIe 3.0 slot runs at the slower speed, so a cheaper Gen 3 drive can be the smarter buy.

Watch for common mistakes too: assuming every M.2 slot is for SSDs (Wi-Fi slots use different keys), and forgetting that some boards disable a SATA port when you use an M.2 slot.
